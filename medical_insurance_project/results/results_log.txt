======================================================================
STAGE 2 — DATA PREPROCESSING & FEATURE ENGINEERING
======================================================================

Dropped exact duplicates: 2772 -> 1337 rows.
  Rationale: the file is the 1,338-row Kaggle set duplicated ~2x.
  Keeping duplicates would leak identical rows across train/test
  and inflate test scores. De-dup BEFORE splitting is essential.

Engineered features:
  - smoker_obese : interaction; isolates the highest-cost segment
  - age2         : captures non-linear (accelerating) age effect
  - obese        : clinical BMI>=30 flag

  Mean charges by (smoker_obese):
smoker_obese
0     9839.0
1    41558.0

Split: train=1069  test=268  (80/20, random)
  No time/index ordering -> random split is appropriate;
  stratification not needed for continuous target.

Preprocessing: StandardScaler(numeric) + OneHot(drop-first, categorical)
  Scaling justified for Linear Regression (coef comparability);
  harmless for trees. One-hot: low-cardinality nominal features.
